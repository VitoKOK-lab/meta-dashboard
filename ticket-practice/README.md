# 搶票演練場 — BIGBANG XX:COSMOS 台北大巨蛋

一個**手機版搶票流程練習模擬器**。用 ticketplus 活動頁公開資訊 + 官方座位圖，
還原臺北大巨蛋的實際分區、票價與「全面啟售」操作節奏，讓你在開賣前把
「選場次 → 選票區 → 驗證碼 → 填實名 → 付款」練到手速夠快。

> ⚠️ 這是**練習模擬工具**：不連線 ticketplus、不送出任何資料、不會購買任何票券。
> 台灣《文創法》第 10-1 條明訂，以電腦程式等不正方式購買藝文票券可處刑責，
> 因此本工具**不做、也不協助任何自動購票**，只幫助使用者手動搶得更快。

## 檔案

- `index.html` — 單一檔案的完整 App（HTML/CSS/JS 內嵌，官方座位圖以 base64 內嵌，離線可用）。

## 功能

- 深空 / 宇宙主題手機介面（呼應本次巡演 XX:COSMOS）
- 全流程計時、分段耗時分析、S/A/B/C 評級、最佳成績（localStorage）
- 互動座位圖：**直接以官方座位圖為底圖**，上面疊透明可點熱區（對齊真實區塊）
  - VIP1 站席 / VIP2 / VIP3、100–500 區、身障優惠席
  - 票區會**隨機且持續售完**（蓋上「售完」），模擬開賣競爭壓力
  - 點色帶可快速標出同價位區
- **我的資料預填**：開賣前先存好參加者（姓名／身分證，最多 4 人）與常用信用卡，
  「填實名」「付款」兩步會自動帶入（僅存於本機 localStorage，不上傳）
- 實名資料格式驗證（身分證字號）、驗證碼、3D 驗證模擬
